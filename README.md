# omarchy-radio-sg

An Omarchy (Hyprland) plugin for listening to Singapore radio stations
(the ones carried on Mediacorp's meLISTEN app, plus SPH stations) —
a Walker station picker, mpv-based playback, and a live Waybar
"now playing" module.

Built spec-first with [OpenSpec](https://github.com/Fission-AI/OpenSpec).
See `openspec/` for the spec workflow; start with `/opsx:propose`.
